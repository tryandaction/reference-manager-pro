# 快速开始（Smart Fix 版）

> 三步完成“官方可信修复”

---

## ✅ 最佳推荐流程（无需 API Key）

1. 打开 `.bib` 文件  
2. 运行 **Reference Manager: Smart Fix**  
3. 运行 **Reference Manager: Validate References**  

> 如果条目含 DOI，Smart Fix 会优先拉取官方元数据并保留原 cite key。

---

## 🧰 批量修复（官方元数据）

当你有大量条目时：

1. 打开 `.bib` 文件  
2. 运行 **Advanced: Smart Fix All (Official)**  
3. 运行 **Validate References**  

---

## 🧾 回滚与审计

任何自动修复都可回滚：

1. 运行 **Reference Manager: History**  
2. 选择变更记录  
3. 一键回滚  

---

## ⚡ 可选：启用 AI 增强

如果你希望 Smart Fix 进一步增强（非必需）：

1. 访问 [console.groq.com](https://console.groq.com) 获取 API Key  
2. 设置 `AI Provider` 为 `groq`  
3. 填入 `Groq Api Key`  

---

## 🧭 推荐日常使用习惯

```
Smart Fix → Validate → (必要时) History 回滚
```
